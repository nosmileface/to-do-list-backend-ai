# Taskflow — To-Do List

Простое веб-приложение для управления задачами, разработанное на Laravel.

## Функциональность

- Авторизация пользователей.
- Создание новых задач.
- Просмотр списка задач.
- Просмотр конкретной задачи.
- Редактирование и удаление задач.
- Отметка задач как выполненных.
- Пагинация списка задач.
- Хранение данных в SQLite.

## Технологии

- PHP 8.4.1+
- Laravel
- SQLite
- Blade
- Tailwind CSS
- Composer

## Установка проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/nosmileface/to-do-list-backend-ai.git
cd  to-do-list-backend-ai
```

### 2. Установка зависимостей

```bash
composer install
```

### 3. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Сгенерируйте ключ приложения:

```bash
php artisan key:generate
```

### 4. Настройка SQLite

Создайте файл базы данных:

```bash
touch database/database.sqlite
```

В файле `.env` укажите:

```dotenv
DB_CONNECTION=sqlite
DB_DATABASE=/абсолютный/путь/к/проекту/database/database.sqlite
```

Замените путь на фактическое расположение файла SQLite.

### 5. Применение миграций

Для создания таблиц выполните:

```bash
php artisan migrate
```

### 6. Заполнение базы тестовыми данными

Для запуска всех сидеров, зарегистрированных в `DatabaseSeeder`:

```bash
php artisan db:seed
```

### 7. Запуск приложения

```bash
php artisan serve
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000

## Структура задач

Каждая задача содержит следующие поля:

| Поле | Описание |
|---|---|
| `id` | Уникальный идентификатор |
| `user_id` | ID владельца задачи |
| `title` | Название задачи |
| `description` | Описание задачи |
| `is_completed` | Статус выполнения: `true` / `false` |
| `created_at` | Дата создания |
| `updated_at` | Дата обновления |

## Безопасность

Каждый пользователь может работать только со своими задачами. Все запросы к задачам ограничиваются идентификатором авторизованного пользователя.

Файл `.env` и база SQLite не должны находиться в публичной директории веб-сервера.
